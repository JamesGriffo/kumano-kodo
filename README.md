# Kumano Kodo photo map

An interactive map of photos from a walk on the Kumano Kodo, Tanabe to Katsuura, 19–24 October 2026.
Each photo is pinned where it was taken. `replay.html` replays the walk in 3D over the terrain.
Published with GitHub Pages.

Map library: MapLibre GL JS (BSD-3-Clause, see `vendor/maplibre-LICENSE.txt`).
Imagery © Esri, Maxar, Earthstar Geographics. Terrain: Mapzen / AWS Terrain Tiles.
